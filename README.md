# 📟 ApertureMonitor v1.0 (Консольный монитор системы)

**ApertureMonitor** — это легковесный автономный виджет для мониторинга ресурсов компьютера в реальном времени, разработанный на чистой Java (Swing). Интерфейс полностью стилизован под классическую командную строку Windows (CMD) с принудительной активацией ретро-режима "color 02" (ярко-зеленый моноширинный текст на черном фоне).

## 🛠️ Основные возможности

* **Matrix/CMD стиль** — интерфейс полностью имитирует консольное окно Windows с выводом системных директорий и заголовков.
* **Мониторинг накопителей** — динамическое считывание общего, занятого и свободного пространства на системном диске C: в гигабайтах.
* **Память JVM** — отображение текущего объема выделенной и используемой оперативной памяти в мегабайтах с ежесекундным пересчетом.
* **Аппаратные данные** — вывод архитектуры операционной системы и количества доступных вычислительных ядер процессора.
* **Полная автономность** — утилита работает без тяжелых графических движков и сторонних библиотек, потребляя минимум ресурсов.

## 📦 Инструкция по установке и запуску

1. Скачайте исходный файл `ApertureMonitor.java` или готовый установщик `ApertureMonitorSetup.exe`.
2. Запустите инсталлятор (собран на базе ретро-движка Inno Setup для быстрой интеграции в систему).
3. Откройте ярлык программы на Рабочем столе — запустится консольное окно, обновляющее статистику нагрузок каждую секунду.
4. Для экстренного закрытия монитора используйте стандартный системный крестик окна.

## ⚙️ Порядок ручной сборки из исходного кода

При необходимости скомпилировать проект вручную используйте стандартный инструментарий JDK:

* Компиляция исходного файла:
  ```bash
  javac ApertureMonitor.java
  ```
* Упаковка скомпилированного байт-кода в исполняемый JAR-архив:
  ```bash
  jar cfe ApertureMonitor.jar ApertureMonitor *.class
  ```
